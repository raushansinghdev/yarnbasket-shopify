# Pinterest: what to do, in order

Prepared in SEO phase 5 (docs/seo-plan.md). The theme is ready; switching on is Raushan's. For a handmade craft shop Pinterest works as a search engine, and a pin keeps sending visits for years.

## Now (the holding site is enough)
1. Make a **Pinterest business account** in the name Yarn Basket, with the store email. Profile photo: the brand kit logo. "About" line: the first sentence of Our story.
2. In Pinterest: Settings → Claimed accounts → Websites → Claim, enter `yarnbasket.in`, choose **Add HTML tag**. Copy only the code inside `content="…"`.
3. In Shopify: Online Store → Themes → Customize → Theme settings → Social. Paste the code into **Pinterest claim code** and the profile's address into **Pinterest profile**. Save.
4. Tell Claude. Claude runs `npm run build:coming-soon` and commits, so the holding site carries the tag. After the push, press **Verify** in Pinterest.

The claim survives the move to Shopify: the theme prints the same tag.

## At launch (password off)
5. Install **Pinterest's Shopify app** and connect the account. It sends the catalogue, so every product becomes a product pin with its price and stock.
6. Nothing to do for rich pins: Pinterest reads the product data and share tags the pages already publish.
7. Make the boards below. Add the board's collection link in its description.

## After launch
- Pin each new product once to its craft board and once to its flower board.
- Pin from the product page, so the pin links back to it.
- No Pinterest button or script is on our pages on purpose (speed).
